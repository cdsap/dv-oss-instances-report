# Develocity OSS instance reports

Reports on recurring build and test failures and avoidable build cache misses for
open-source Develocity instances. Each run adds its reports here; earlier reports
stay, so the site keeps the history of every instance.

Browse them at https://cdsap.github.io/dv-oss-instances-report/.

This repository is written by an automated pipeline, so pull requests against it
are not merged.
